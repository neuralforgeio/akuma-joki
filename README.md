# AKUMA JOKI 🎮

Joki & Store Roblox — Retro PixelArt theme (Next.js 16 App Router + Tailwind + Framer Motion + Zustand).

## Menjalankan Secara Lokal

```bash
npm install
npm run dev
# buka http://localhost:3000
```

Script sudah cross-platform (Windows / macOS / Linux).

## Mode Maintenance (Takedown)

Edit **`config.json`** di root folder:
- `isTakedown: true` → SEMUA route redirect ke `/takedown`
- `isTakedown: false` → website normal

## Route
- `/` Home
- `/store/blox-fruits` | `/store/expedition-antarctica` | `/store/retail-tycoon-2`
- `/checkout`
- `/takedown` (otomatis saat maintenance on)
